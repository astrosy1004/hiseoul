# HiSeoul (하이서울)

K-팝·K-뷰티에 관심 있는 외국인 여행객을 위한 쇼핑 웹앱입니다. 분야별 베스트 아이템을 사면 **묵고 있는 호텔 프런트로 당일 배달**해 줍니다.

> 현재는 데모 버전입니다. 상품, 가격, 호텔, 환율은 모두 예시 데이터이고 결제와 배송은 실제로 일어나지 않습니다.

## 핵심 기능

| 기능 | 설명 | 위치 |
|---|---|---|
| 분야별 베스트 | K-뷰티, K-팝, K-패션, K-간식, K-웰니스 랭킹 | `/category/[slug]` |
| 트렌드 레이더 | 지금 여행객이 많이 사는 급상승 상품 | 홈 |
| 당일 호텔 배달 | 호텔 검색, 예약자명, 객실, 배달 날짜·시간대 선택 | `/checkout` |
| 배달 추적 | 주문 확인 → 매장 픽업 → 이동 중 → 프런트 전달 | `/orders/[id]` |
| 택스리펀 자동 계산 | 결제 전 예상 환급액 표시 (여권번호 입력) | 장바구니·결제 |
| 캐리어 무게 미터 | 장바구니 무게로 수하물 초과 경고 | 장바구니·결제 |
| 본국 배송 옵션 | 무거운 상품은 본국으로 바로 발송 | 결제 |
| AI 피부 매칭 | 질문 3개로 피부 타입별 K-스킨케어 루틴 추천 | `/skin-match` |
| 다국어·다통화 | 영어/일본어/중국어/한국어, USD/JPY/CNY/EUR/KRW | 상단 바 |

## 기술 스택

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS 4
- 상태: React Context + localStorage (장바구니, 주문, 언어, 통화)

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드 확인
```

## 폴더 구조

```
src/
  app/            페이지 (홈, 카테고리, 상품, 장바구니, 결제, 주문추적, 피부매칭)
  components/     헤더, 상품 카드, 금액/캐리어 요약
  lib/data.ts     상품·호텔·환율 예시 데이터, 택스리펀 계산
  lib/i18n.ts     다국어 문구
  lib/store.tsx   장바구니·주문 상태
```
